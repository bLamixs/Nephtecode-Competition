# Управляемые параметры оптимизатора

## Обоснование выбора

Выбраны 4 управляемых параметра + 6 долей блендинга на основе:
1. Влияния на качество ДТ (сера, T95, CFPP).
2. Возможности оперативного изменения (уставки в АСУ ТП).
3. Технологических ограничений и реальных статистических диапазонов по исторической телеметрии (177+ тыс. строк активного технологического режима).

## Параметры

### T6 — температура реактора гидроочистки (Р-201)

- **Диапазон:** 345–375°C (номинал 360°C).
- **Эмпирические данные телеметрии:** медиана 363.3°C, среднее 363.8°C, $p_{05} = 347.1^\circ\text{C}$, $p_{95} = 380.5^\circ\text{C}$.
- **Влияние:** глубина гидроочистки, содержание серы.
- **Обоснование:** повышение T6 на 3°C снижает серу на ~1.5–2.0 мг/кг.
- **Ограничение:** не выше 375–380°C (критический предел оборудования: 380°C, риск ускоренной деградации и закоксовывания катализатора).

### F2_F26_ratio — соотношение ВСГ/сырьё

- **Диапазон:** 0.80–0.95 (номинал 0.85).
- **Влияние:** парциальное давление водорода в зоне реакции, сера.
- **Обоснование:** повышение соотношения улучшает гидроочистку.
- **Ограничение:** не выше 0.95 (ограничение по производительности компрессоров ВСГ).

### T55 — температура печи П-3 (П-1/1)

- **Диапазон:** 375–386°C (номинал 380°C).
- **Эмпирические данные телеметрии:** медиана 381.7°C, среднее 381.0°C, $p_{05} = 378.2^\circ\text{C}$, $p_{95} = 385.0^\circ\text{C}$.
- **Влияние:** нагрев нефти перед колонной АВТ, четкость фракционирования.
- **Обоснование:** влияет на выход и температуры выкипания фракций 240-350°C.
- **Ограничение:** не выше 386°C (риск термического разложения и коксования змеевиков печи).

### F9 — расход сырья на гидроочистку (F9_avt)

- **Диапазон:** 160–280 т/ч (номинал 215 т/ч).
- **Эмпирические данные телеметрии:** медиана 211.7 т/ч, среднее 217.4 т/ч, $p_{05} = 143.6$ т/ч, $p_{90} = 269.3$ т/ч.
- **Влияние:** производительность установки, время контакта в слое катализатора (WHSV).
- **Обоснование:** снижение F9 увеличивает время контакта → глубже обессеривание.
- **Ограничение:** не ниже 160 т/ч (минимальная технологическая загрузка циркуляционных насосов).

## Доли блендинга

Сумма долей = 1.0 (100%). Диапазоны рассчитаны по фактическим пропорциям расходов фракций в телеметрии.

## Допущения

1. **Диапазоны подтверждены реальной телеметрией**: границы построены по 5-м и 95-м процентилям активного технологического режима с отсечением простоев.
2. **Сумма долей = 1.0**: нормализация через Dirichlet distribution.
3. **T6 — главный регулятор серы**: рабочая точка 360°C соответствует базовой сере ~8.4 мг/кг.
4. **Безопасность по сере**: требование ГОСТ Евро-5 $\le 10.0$ мг/кг строго соблюдается как жесткое ограничение (veto).
5. **Предел реактора**: температура катализатора не должна превышать 380°C.
